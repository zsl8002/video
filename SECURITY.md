# Security Policy

Report vulnerabilities privately through GitHub Security Advisories. Never publish credentials, cookies, private media URLs or personal data in an issue.

Source entries are user-provided HTTP(S) URLs and are never executed as code. The project does not bundle remote parser scripts, credential extraction, DRM circumvention or paywall bypass services. Never commit API tokens, signing keys, provisioning profiles or cookies. Treat third-party media and metadata as untrusted input.
